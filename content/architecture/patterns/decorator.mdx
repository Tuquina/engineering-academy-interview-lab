## Motivación

El cliente que consulta el costo de envío a un código postal en la API de un transportista necesita reintentos ante
errores transitorios, una caché de cinco minutos (la tarifa no cambia tan rápido) y métricas de latencia. Son tres
preocupaciones independientes y no todas aplican en todos los entornos.

## Ejemplo incorrecto

```ts
class ShippingRatesClient {
  private cache = new Map<string, { priceCents: number; at: number }>();

  async quote(postalCode: string): Promise<number> {
    const cached = this.cache.get(postalCode);
    if (cached && Date.now() - cached.at < 300_000) return cached.priceCents;
    const started = performance.now();
    for (let attempt = 1; ; attempt++) {
      try {
        const res = await fetch(`https://carrier.example/rates/${postalCode}`);
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const { priceCents } = (await res.json()) as { priceCents: number };
        this.cache.set(postalCode, { priceCents, at: Date.now() });
        metrics.observe("shipping_rates_latency_ms", performance.now() - started);
        return priceCents;
      } catch (error) {
        if (attempt === 3) throw error;
        await new Promise((r) => setTimeout(r, 200 * attempt));
      }
    }
  }
}
```

La llamada HTTP, la caché, los reintentos y las métricas están entrelazados. No se puede probar uno sin los otros
ni desactivar la caché en tests.

## Implementación correcta

```ts
export interface ShippingRates {
  quote(postalCode: string): Promise<number>;
}

export class HttpShippingRates implements ShippingRates {
  async quote(postalCode: string): Promise<number> {
    const res = await fetch(`https://carrier.example/rates/${postalCode}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return ((await res.json()) as { priceCents: number }).priceCents;
  }
}

export class RetryingShippingRates implements ShippingRates {
  constructor(
    private readonly inner: ShippingRates,
    private readonly attempts = 3,
  ) {}
  async quote(postalCode: string): Promise<number> {
    for (let attempt = 1; ; attempt++) {
      try {
        return await this.inner.quote(postalCode);
      } catch (error) {
        if (attempt >= this.attempts) throw error;
        await new Promise((resolve) => setTimeout(resolve, 200 * 2 ** (attempt - 1)));
      }
    }
  }
}

export class CachedShippingRates implements ShippingRates {
  private readonly cache = new Map<string, { priceCents: number; expiresAt: number }>();
  constructor(
    private readonly inner: ShippingRates,
    private readonly ttlMs: number,
    private readonly now = Date.now,
  ) {}
  async quote(postalCode: string): Promise<number> {
    const hit = this.cache.get(postalCode);
    if (hit && hit.expiresAt > this.now()) return hit.priceCents;
    const priceCents = await this.inner.quote(postalCode); // los errores no se cachean
    this.cache.set(postalCode, { priceCents, expiresAt: this.now() + this.ttlMs });
    return priceCents;
  }
}

// Composición: la caché por fuera, los reintentos envolviendo la llamada real.
export const shippingRates: ShippingRates = new CachedShippingRates(
  new RetryingShippingRates(new HttpShippingRates()),
  300_000,
);
```

## Ejercicio

Agregá un decorador que registre la latencia de cada llamada. ¿Dónde lo ubicarías en la pila si querés medir la
latencia que percibe el usuario, incluidos los aciertos de caché?

<Reveal>

```ts
export class TimedShippingRates implements ShippingRates {
  constructor(
    private readonly inner: ShippingRates,
    private readonly observe: (ms: number) => void,
  ) {}
  async quote(postalCode: string): Promise<number> {
    const started = performance.now();
    try {
      return await this.inner.quote(postalCode);
    } finally {
      this.observe(performance.now() - started);
    }
  }
}
```

Para medir lo que percibe el usuario va por fuera de todo: `new TimedShippingRates(new CachedShippingRates(...))`. Si en
cambio querés medir sólo la latencia del proveedor, va justo alrededor de `HttpShippingRates`. Ambas métricas son
útiles y pueden coexistir.

</Reveal>
