## Motivación

Una plataforma de cobranzas prioriza a quién contactar primero. Cada tenant (cada empresa cliente) tiene su
criterio: una financiera prioriza el monto vencido, otra la antigüedad de la mora y otra la probabilidad de pago
estimada. El criterio cambia por tenant y se agregan criterios nuevos cuando entra un cliente nuevo.

## Ejemplo incorrecto

```ts
function priority(debt: Debt, tenant: Tenant): number {
  if (tenant.plan === "financiera") {
    return debt.overdueCents / 100;
  } else if (tenant.plan === "retail") {
    return debt.daysOverdue * 2 + (debt.hasPromise ? -50 : 0);
  } else if (tenant.id === "acme") {
    // Caso especial agregado de urgencia
    return debt.daysOverdue > 90 ? 1000 : debt.overdueCents / 1000;
  }
  return 0;
}
```

Cada tenant nuevo modifica esta función, los casos especiales se mezclan con la regla general y no hay forma de
probar un criterio sin pasar por todos los demás.

## Implementación correcta

```ts
export interface DebtSnapshot {
  readonly overdueCents: number;
  readonly daysOverdue: number;
  readonly hasActivePromise: boolean;
}

/** Una estrategia es una función pura: mayor número, mayor prioridad. */
export type PriorityStrategy = (debt: DebtSnapshot) => number;

export const byAmount: PriorityStrategy = (debt) => debt.overdueCents;

export const byAge: PriorityStrategy = (debt) => debt.daysOverdue * 100 - (debt.hasActivePromise ? 5_000 : 0);

const STRATEGIES = { "by-amount": byAmount, "by-age": byAge } satisfies Record<string, PriorityStrategy>;
export type StrategyId = keyof typeof STRATEGIES;

/** La selección ocurre en un único lugar, a partir de la configuración del tenant. */
export function prioritize(debts: readonly DebtSnapshot[], strategyId: StrategyId): DebtSnapshot[] {
  const strategy = STRATEGIES[strategyId];
  return [...debts].sort((a, b) => strategy(b) - strategy(a));
}
```

Agregar un criterio es agregar una función y una clave. `satisfies` verifica que todas cumplan la firma y
`StrategyId` impide configurar un criterio inexistente.

## Ejercicio

Un tenant pide combinar criterios: 70% monto y 30% antigüedad. ¿Cómo lo agregarías sin modificar `byAmount` ni
`byAge`?

<Reveal>

Con una estrategia que compone otras. Como cada criterio tiene escalas distintas, conviene normalizarlos antes de
combinarlos; aquí se muestra la idea:

```ts
export const weighted =
  (parts: ReadonlyArray<{ strategy: PriorityStrategy; weight: number }>): PriorityStrategy =>
  (debt) =>
    parts.reduce((total, { strategy, weight }) => total + strategy(debt) * weight, 0);

const mixed = weighted([
  { strategy: byAmount, weight: 0.7 },
  { strategy: byAge, weight: 0.3 },
]);
```

Las estrategias existentes no cambian y la nueva se prueba con casos concretos.

</Reveal>
