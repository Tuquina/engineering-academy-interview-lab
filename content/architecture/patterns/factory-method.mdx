## Motivación

Una aplicación envía notificaciones por email, SMS o push según la preferencia de cada usuario. Cada proveedor tiene su
cliente, credenciales y opciones (reintentos, remitente).

## Ejemplo incorrecto

```ts
async function notify(user: User, message: string) {
  if (user.channel === "email") {
    const client = new SesClient({ region: "us-east-1", from: "no-reply@shop.com" });
    await client.send(user.email, message);
  } else if (user.channel === "sms") {
    const client = new TwilioClient(process.env.TWILIO_SID!, process.env.TWILIO_TOKEN!);
    await client.sms(user.phone, message);
  }
  // …el mismo if aparece en el recordatorio, el reseteo de contraseña y el resumen semanal
}
```

## Implementación correcta

```ts
export interface Notifier {
  send(user: User, message: string): Promise<void>;
}

export type Channel = "email" | "sms" | "push";

export function createNotifierFactory(config: NotificationConfig) {
  // Los clientes se crean una vez; la fábrica sólo elige.
  const notifiers: Record<Channel, Notifier> = {
    email: new EmailNotifier(new SesClient(config.ses)),
    sms: new SmsNotifier(new TwilioClient(config.twilio)),
    push: new PushNotifier(config.push),
  };
  return (channel: Channel): Notifier => notifiers[channel];
}

// Uso
const notifierFor = createNotifierFactory(config);
await notifierFor(user.channel).send(user, message);
```

Agregar un canal es agregar una implementación y una entrada. En los tests se pasa una fábrica que devuelve un
notificador en memoria.

## Ejercicio

Ahora algunos usuarios quieren recibir por **dos** canales a la vez. ¿Cómo lo resolvés sin tocar los notificadores?

<Reveal>

Con un notificador compuesto (patrón **Composite**) que implementa la misma interfaz y delega en varios:

```ts
class MultiNotifier implements Notifier {
  constructor(private readonly notifiers: readonly Notifier[]) {}
  async send(user: User, message: string) {
    await Promise.allSettled(this.notifiers.map((n) => n.send(user, message)));
  }
}

const notifier = new MultiNotifier(user.channels.map(notifierFor));
```

La fábrica sigue eligiendo implementaciones simples y el cliente no se entera de que son varias.

</Reveal>
