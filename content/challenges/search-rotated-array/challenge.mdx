## Enunciado

Un array ordenado de forma ascendente, con valores distintos, fue **rotado** en una posición desconocida
(`[0, 1, 2, 4, 5, 6, 7]` → `[4, 5, 6, 7, 0, 1, 2]`). Devolvé el índice de `target` o `-1` si no está, en **O(log n)**.

```ts
export function searchRotated(nums: readonly number[], target: number): number;
```

## Ejemplos

| `nums`                  | `target` | Resultado |
| ----------------------- | -------- | --------- |
| `[4, 5, 6, 7, 0, 1, 2]` | `0`      | `4`       |
| `[4, 5, 6, 7, 0, 1, 2]` | `3`      | `-1`      |
| `[1]`                   | `1`      | `0`       |
| `[1, 3]`                | `3`      | `1`       |
