## Contexto

Hay que enviar recordatorios a 10.000 clientes a través de una API que admite 10 requests simultáneas. Con
`Promise.all` sobre todo el lote se dispararían 10.000 requests a la vez; con un `for` y `await` se tardaría
demasiado. Un **limitador de concurrencia** ejecuta como máximo N tareas a la vez y encola el resto.

## Qué tenés que implementar

```ts
export interface Limiter {
  <T>(task: () => Promise<T>): Promise<T>;
  readonly activeCount: number;
  readonly pendingCount: number;
}

export function createLimiter(concurrency: number): Limiter;
```

## Ejemplo

```ts
const limit = createLimiter(10);
const results = await Promise.all(customers.map((c) => limit(() => sendReminder(c))));
```

## Casos límite

- Una tarea que lanza de forma síncrona (antes de devolver la promesa) también debe liberar su lugar.
- `concurrency` mayor que la cantidad de tareas: todas corren a la vez.
