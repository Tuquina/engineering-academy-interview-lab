## Enunciado

Dada una lista de palabras, agrupá las que son **anagramas** entre sí (mismas letras, con la misma cantidad de cada
una, en cualquier orden).

```ts
export function groupAnagrams(words: readonly string[]): string[][];
```

## Ejemplo

```ts
groupAnagrams(["eat", "tea", "tan", "ate", "nat", "bat"]);
// [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

- Los grupos aparecen en el orden de su primera palabra (`"eat"`, luego `"tan"`, luego `"bat"`).
- Dentro de cada grupo se conserva el orden original.
- `[""]` devuelve `[[""]]` y `[]` devuelve `[]`.
