## Enunciado

Dado un string `s`, devolvé la **longitud** de la subcadena **contigua** más larga que no repite ningún carácter.

```ts
export function lengthOfLongestSubstring(s: string): number;
```

## Ejemplos

| `s`          | Resultado | Subcadena |
| ------------ | --------- | --------- |
| `"abcabcbb"` | `3`       | `"abc"`   |
| `"bbbbb"`    | `1`       | `"b"`     |
| `"pwwkew"`   | `3`       | `"wke"`   |
| `""`         | `0`       |           |

`"pwke"` no cuenta: es una subsecuencia, no una subcadena contigua.
