## Contexto

Un agente de voz envía eventos de "el cliente está hablando" decenas de veces por segundo. El panel de supervisión
quiere actualizar su indicador como máximo cada 100 ms, pero sin perder el **último** estado. Eso es un throttle con
ejecución inicial (leading) y final (trailing).

## Qué tenés que implementar

```ts
export type Throttled<A extends unknown[]> = ((...args: A) => void) & { cancel(): void };

export function throttle<A extends unknown[]>(fn: (...args: A) => void, intervalMs: number): Throttled<A>;
```

## Ejemplo con `intervalMs = 100`

| Tiempo | Llamada     | Ejecución                         |
| ------ | ----------- | --------------------------------- |
| 0 ms   | `update(1)` | `fn(1)` inmediato                 |
| 20 ms  | `update(2)` | —                                 |
| 60 ms  | `update(3)` | —                                 |
| 100 ms |             | `fn(3)` (trailing)                |
| 250 ms | `update(4)` | `fn(4)` inmediato (ventana nueva) |

## Casos límite

- Una sola llamada no debe producir una ejecución final adicional.
- `cancel()` sin nada pendiente no falla.
