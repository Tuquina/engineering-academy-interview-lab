## Enunciado

Dado un array de intervalos `[inicio, fin]`, fusioná todos los que se **superponen** y devolvé el resultado ordenado
por inicio.

```ts
export function mergeIntervals(intervals: readonly (readonly [number, number])[]): [number, number][];
```

## Ejemplos

| Entrada                               | Resultado                     |
| ------------------------------------- | ----------------------------- |
| `[[1, 3], [2, 6], [8, 10], [15, 18]]` | `[[1, 6], [8, 10], [15, 18]]` |
| `[[1, 4], [4, 5]]`                    | `[[1, 5]]`                    |
| `[[1, 10], [2, 3]]`                   | `[[1, 10]]`                   |
| `[[5, 6], [1, 2]]`                    | `[[1, 2], [5, 6]]`            |
| `[]`                                  | `[]`                          |
