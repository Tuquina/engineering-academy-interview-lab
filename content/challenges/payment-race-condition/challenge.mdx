## Contexto

El servicio de cobros descuenta saldo de una cuenta prepaga cuando un agente confirma un pago con tarjeta. Una
noche, dos confirmaciones del mismo cliente llegaron casi a la vez y la cuenta quedó en **−40**: ambas leyeron
saldo 100, ambas verificaron que alcanzaba para 70 y ambas escribieron 30.

## Código actual (con el bug)

```ts
async charge(accountId: string, amount: number) {
  const balance = await this.repo.getBalance(accountId); // ambos leen 100
  if (balance < amount) throw new InsufficientFundsError(accountId);
  await this.repo.setBalance(accountId, balance - amount); // ambos escriben 30
}
```

## Qué tenés que implementar

```ts
export class PaymentService {
  constructor(repo: BalanceRepository);
  charge(accountId: string, amount: number): Promise<number>; // devuelve el saldo nuevo
}
```

## Casos límite

- Muchos cobros concurrentes sobre la misma cuenta: el saldo final debe ser exacto.
- Un error del repositorio en un cobro no debe impedir los siguientes.
