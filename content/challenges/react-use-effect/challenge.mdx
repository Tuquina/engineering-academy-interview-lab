## Contexto

En el panel de atención al cliente de una tienda, al pasar rápido de un cliente a otro, a veces se ven **los pedidos del cliente anterior**.
El componente vive en `App.tsx`; el preview incluye una API falsa en la que "Ana" responde lento y "Bruno" rápido,
para reproducir el problema: elegí Ana y enseguida Bruno.

## Qué tenés que hacer

Corregí `CustomerOrders` para que:

1. Cargue los pedidos cuando se monta **y cada vez que cambia `customerId`**.
2. Ignore respuestas de un `customerId` anterior (condición de carrera).
3. Muestre «Cargando…» mientras espera.

Los tests (`App.test.tsx`) se ejecutan con Jest en el navegador desde el panel de tests.
