## Enunciado

Dado un string `s` con los caracteres `(`, `)`, `[`, `]`, `{` y `}`, determiná si es **válido**:

1. Cada apertura se cierra con el **mismo tipo**.
2. Las aperturas se cierran en el **orden correcto**.
3. Cada cierre corresponde a una apertura previa.

```ts
export function isValid(s: string): boolean;
```

## Ejemplos

| `s`        | Resultado |
| ---------- | --------- |
| `"()[]{}"` | `true`    |
| `"([{}])"` | `true`    |
| `"(]"`     | `false`   |
| `"([)]"`   | `false`   |
| `"(("`     | `false`   |
| `""`       | `true`    |
