## Contexto

El buscador de clientes del panel de operadores consulta la API en cada tecla. Con un operador escribiendo rápido,
eso son decenas de requests por segundo que no aportan nada: sólo interesa el texto final. **Debounce** agrupa una
ráfaga de llamadas y ejecuta la función una sola vez, cuando las llamadas dejan de llegar durante `waitMs`.

## Qué tenés que implementar

```ts
export type Debounced<A extends unknown[]> = ((...args: A) => void) & { cancel(): void };

export function debounce<A extends unknown[]>(fn: (...args: A) => void, waitMs: number): Debounced<A>;
```

## Ejemplo

```ts
const search = debounce((term: string) => api.search(term), 300);
search("d");
search("de");
search("deu"); // 300 ms después de esta llamada se ejecuta api.search("deu") una sola vez
```

## Casos límite a considerar

- Llamar a `cancel()` sin nada pendiente no debe fallar.
- Con `waitMs = 0` la ejecución igual es asíncrona (no ocurre dentro de la llamada).
- Después de ejecutarse, una llamada nueva inicia una ráfaga nueva.
