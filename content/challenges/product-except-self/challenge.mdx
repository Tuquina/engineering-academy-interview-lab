## Enunciado

Dado un array `nums`, devolvé un array `result` donde `result[i]` es el producto de **todos los elementos de `nums`
excepto `nums[i]`**, sin usar la división.

```ts
export function productExceptSelf(nums: readonly number[]): number[];
```

## Ejemplos

| `nums`              | Resultado         |
| ------------------- | ----------------- |
| `[1, 2, 3, 4]`      | `[24, 12, 8, 6]`  |
| `[-1, 1, 0, -3, 3]` | `[0, 0, 9, 0, 0]` |
| `[2, 3]`            | `[3, 2]`          |

Los resultados entran en el rango de enteros seguros de JavaScript.
