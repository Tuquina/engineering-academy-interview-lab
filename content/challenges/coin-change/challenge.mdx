## Enunciado

Dadas las denominaciones `coins` (cantidad ilimitada de cada una) y un monto `amount`, devolvé la **mínima cantidad de
monedas** que suman exactamente `amount`, o `-1` si no es posible.

```ts
export function coinChange(coins: readonly number[], amount: number): number;
```

## Ejemplos

| `coins`     | `amount` | Resultado | Por qué                        |
| ----------- | -------- | --------- | ------------------------------ |
| `[1, 2, 5]` | `11`     | `3`       | 5 + 5 + 1                      |
| `[2]`       | `3`      | `-1`      | imposible                      |
| `[1]`       | `0`      | `0`       | ninguna moneda                 |
| `[1, 3, 4]` | `6`      | `2`       | 3 + 3 (el greedy da 4 + 1 + 1) |
