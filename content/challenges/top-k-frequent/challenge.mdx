## Enunciado

Dado un array de enteros `nums` y un entero `k`, devolvé los `k` valores **más frecuentes**.

```ts
export function topKFrequent(nums: readonly number[], k: number): number[];
```

El resultado va de **mayor a menor frecuencia**; si dos valores aparecen la misma cantidad de veces, va primero el
**menor**.

## Ejemplos

| `nums`               | `k` | Resultado |
| -------------------- | --- | --------- |
| `[1, 1, 1, 2, 2, 3]` | `2` | `[1, 2]`  |
| `[4, 4, 7, 7, 9]`    | `2` | `[4, 7]`  |
| `[5]`                | `1` | `[5]`     |
| `[-1, -1, 2, 2, 2]`  | `1` | `[2]`     |
