## Enunciado

Hay `n` materias numeradas de `0` a `n - 1` y una lista de **correlativas**: `[a, b]` significa que para cursar `a`
primero hay que aprobar `b`. Devolvé un **orden** en el que se puedan cursar todas, o `null` si es imposible.

```ts
export function findOrder(n: number, prerequisites: readonly (readonly [number, number])[]): number[] | null;
```

## Ejemplos

| `n` | `prerequisites`                    | Un resultado válido             |
| --- | ---------------------------------- | ------------------------------- |
| `2` | `[[1, 0]]`                         | `[0, 1]`                        |
| `4` | `[[1, 0], [2, 0], [3, 1], [3, 2]]` | `[0, 1, 2, 3]` o `[0, 2, 1, 3]` |
| `2` | `[[1, 0], [0, 1]]`                 | `null` (ciclo)                  |
| `1` | `[]`                               | `[0]`                           |

Cualquier orden válido es aceptado.
