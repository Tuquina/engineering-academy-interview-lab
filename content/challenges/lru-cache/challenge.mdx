## Enunciado

Implementá una caché **LRU** (Least Recently Used) de capacidad fija: cuando está llena y se inserta una clave nueva,
se descarta la que se usó **hace más tiempo**. Leer o escribir una clave cuenta como uso.

```ts
export class LRUCache<K, V> {
  constructor(capacity: number);
  get(key: K): V | undefined;
  put(key: K, value: V): void;
  get size(): number;
}
```

## Ejemplo

```ts
const cache = new LRUCache<string, number>(2);
cache.put("a", 1);
cache.put("b", 2);
cache.get("a"); // 1 → ahora "b" es la menos usada
cache.put("c", 3); // capacidad superada: se elimina "b"
cache.get("b"); // undefined
cache.get("c"); // 3
```

Es la política de desalojo que usan, en variantes aproximadas, Redis (`allkeys-lru`) y muchas cachés de aplicación.
