## Enunciado

Dado un array de enteros `nums` y un entero `target`, devolvé los **índices** de los dos números que suman `target`.

```ts
export function twoSum(nums: number[], target: number): [number, number];
```

## Ejemplos

| `nums`           | `target` | Resultado |
| ---------------- | -------- | --------- |
| `[2, 7, 11, 15]` | `9`      | `[0, 1]`  |
| `[3, 2, 4]`      | `6`      | `[1, 2]`  |
| `[3, 3]`         | `6`      | `[0, 1]`  |
| `[-4, 1, 9, 0]`  | `-4`     | `[0, 3]`  |

Los índices se devuelven en orden ascendente.
