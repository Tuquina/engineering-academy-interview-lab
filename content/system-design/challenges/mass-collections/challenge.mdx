Una plataforma de cobranzas recibe la cartera de deudas de varias empresas (tenants). Cada día llegan altas de
deudas, actualizaciones de saldo y pagos, por API en tiempo real y en archivos nocturnos. A partir de esos datos,
el sistema decide **a quién contactar primero** y registra cada gestión.

El sistema actual procesa todo de forma síncrona dentro de la request: cuando un tenant grande sube su archivo, la
API se vuelve lenta para todos, algunos pagos se aplicaron dos veces tras reintentos del proveedor, y no hay forma
de explicar por qué cambió el saldo de un cliente.

Diseñá el sistema de ingesta, procesamiento y priorización.
