## Qué es Java

**Java** es un lenguaje de propósito general, orientado a objetos y **estáticamente tipado**, creado por Sun
Microsystems en 1995 y hoy mantenido por Oracle y la comunidad en el proyecto **OpenJDK**. Es uno de los lenguajes
más usados en backend empresarial: bancos, e-commerce, telecomunicaciones y gran parte de los sistemas que procesan
pagos, pedidos o reservas corren sobre la **JVM**.

Su promesa original fue "escribir una vez, ejecutar en cualquier lado": el código no se compila a código de máquina
de un sistema operativo, sino a **bytecode**, que ejecuta la Java Virtual Machine.

| Pieza        | Qué es                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------- |
| `javac`      | Compilador: transforma archivos `.java` en archivos `.class` con bytecode.                     |
| JVM          | Máquina virtual que carga clases, interpreta y compila (JIT) el bytecode y administra memoria. |
| JDK          | Kit de desarrollo: JVM, librería estándar y herramientas (`javac`, `jar`, `jshell`, `jdb`).    |
| Distribución | Builds del JDK de distintos proveedores: Eclipse Temurin, Amazon Corretto, Oracle, Azul.       |

### Versiones

Java publica una versión nueva cada seis meses. Cada dos años una es **LTS** (Long-Term Support): recibe
actualizaciones durante años y es la que se usa en producción. Las LTS más recientes son **Java 17** (2021),
**Java 21** (2023) y **Java 25** (2025). Spring Boot 4 requiere al menos Java 17.

Para este curso podés usar la imagen oficial `eclipse-temurin` de Docker, sin instalar nada en tu máquina:

```bash
docker run --rm -it -v "$PWD":/app -w /app eclipse-temurin:21-jdk jshell
```

`jshell` es una consola interactiva (REPL) ideal para probar sintaxis.

## Tu primer programa

```java
// Main.java
public class Main {
    public static void main(String[] args) {
        String name = args.length > 0 ? args[0] : "mundo";
        System.out.println("Hola, " + name + "!");
    }
}
```

```bash
javac Main.java     # genera Main.class
java Main Ana       # Hola, Ana!
java Main.java Ana  # desde Java 11 se puede ejecutar un archivo fuente directamente
```

Puntos a notar:

- **Todo vive dentro de una clase.** El archivo se llama igual que la clase pública que contiene.
- `public static void main(String[] args)` es el punto de entrada. `static` significa que pertenece a la clase y
  no a una instancia.
- Cada sentencia termina en `;` y los bloques van entre llaves.

## Tipos y variables

Java tiene dos familias de tipos:

| Primitivos                     | Tamaño             | Ejemplo                        |
| ------------------------------ | ------------------ | ------------------------------ |
| `boolean`                      | —                  | `boolean active = true;`       |
| `byte`, `short`, `int`, `long` | 8, 16, 32, 64 bits | `long total = 3_000_000_000L;` |
| `float`, `double`              | 32, 64 bits        | `double rate = 0.21;`          |
| `char`                         | 16 bits (UTF-16)   | `char initial = 'A';`          |

Todo lo demás son **tipos de referencia**: `String`, arrays, clases e interfaces. Una variable de referencia guarda
una referencia a un objeto en el heap, o `null`.

```java
int quantity = 3;                 // primitivo
Integer boxed = quantity;         // autoboxing: el wrapper es un objeto y puede ser null
var price = 1250.50;              // var infiere double (sólo en variables locales)
final String currency = "ARS";    // final: no se puede reasignar
```

<Callout type="warning" title="No uses double para dinero">
  `double` es binario de punto flotante: `0.1 + 0.2` no da exactamente `0.3`. Para montos usá `BigDecimal` o
  enteros en la unidad mínima (centavos como `long`).
</Callout>

`var` no hace a Java dinámico: el tipo se infiere en compilación y no cambia. Los wrappers (`Integer`, `Long`,
`Double`…) existen porque las colecciones sólo guardan objetos; cuidado con comparar wrappers con `==` y con el
`NullPointerException` al desempaquetar un `null`.

## Control de flujo

```java
if (stock == 0) {
    status = "agotado";
} else if (stock < 5) {
    status = "últimas unidades";
} else {
    status = "disponible";
}

for (int i = 0; i < items.length; i++) { /* ... */ }
for (String item : items) { /* for-each sobre arrays y colecciones */ }
while (retries < 3) { retries++; }

// switch como expresión (Java 14+): sin fall-through y debe cubrir todos los casos
String label = switch (status) {
    case "PAID" -> "Pagado";
    case "SHIPPED", "DELIVERED" -> "Enviado";
    default -> "Pendiente";
};
```

El `switch` con flechas devuelve un valor y no "cae" al caso siguiente, a diferencia del `switch` clásico con
`case X:` y `break`.

## Métodos y clases

```java
public class Order {
    private final String id;          // campo privado: encapsulamiento
    private long totalCents;

    public Order(String id) {         // constructor
        this.id = id;
    }

    public void addItem(long priceCents, int quantity) {
        if (quantity <= 0) throw new IllegalArgumentException("Cantidad inválida");
        totalCents += priceCents * quantity;
    }

    public long getTotalCents() {     // getter: convención JavaBeans
        return totalCents;
    }

    public static Order empty(String id) {  // método estático "de fábrica"
        return new Order(id);
    }
}

Order order = new Order("o-1");
order.addItem(1500, 2);
System.out.println(order.getTotalCents()); // 3000
```

- Los modificadores de acceso son `public`, `protected`, sin modificador (visible en el paquete) y `private`.
- Los métodos se pueden **sobrecargar**: mismo nombre, distintos parámetros.
- Java pasa los argumentos **siempre por valor**. Con objetos, se copia la referencia: el método puede modificar el
  objeto, pero no hacer que la variable del llamador apunte a otro.

## Strings y arrays

```java
String a = "hola";
String b = new String("hola");
a == b;          // false: son objetos distintos
a.equals(b);     // true: mismo contenido

String text = "  Zapatillas Running  ";
text.trim().toLowerCase().contains("running"); // true
String.format("Total: %d centavos", 3000);
String message = """
    Bloque de texto (Java 15+):
    respeta saltos de línea.
    """;

int[] stock = {5, 0, 12};
stock.length;                 // 3 (los arrays tienen tamaño fijo)
int[][] matrix = new int[3][4];
```

Los `String` son **inmutables**: cada operación devuelve uno nuevo. Para concatenar muchas veces en un bucle se usa
`StringBuilder`, que evita crear miles de objetos intermedios.

## Paquetes, imports y un proyecto con Maven

Las clases se organizan en **paquetes** que siguen la estructura de carpetas (`com.shop.orders`). Un proyecto real no
se compila con `javac` a mano: se usa **Maven** o **Gradle**, que descargan dependencias, compilan, ejecutan tests y
empaquetan.

```text
shop/
├── pom.xml                         # dependencias y configuración de Maven
└── src/
    ├── main/java/com/shop/App.java
    └── test/java/com/shop/AppTest.java
```

```xml
<dependency>
  <groupId>org.junit.jupiter</groupId>
  <artifactId>junit-jupiter</artifactId>
  <scope>test</scope>
</dependency>
```

Comandos habituales: `mvn test`, `mvn package` (genera el `.jar`) y `mvn spring-boot:run` en proyectos Spring Boot.
Gradle cumple el mismo rol con un archivo `build.gradle(.kts)`.

## Resumen

Java compila a bytecode que ejecuta la JVM; usá una versión LTS. La sintaxis gira alrededor de clases, tipos
estáticos, primitivos y referencias. Con esto ya podés escribir programas: en la próxima lección vemos cómo modelar con
objetos, interfaces, records y el Collections Framework.
