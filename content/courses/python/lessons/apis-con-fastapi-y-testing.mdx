## El ecosistema web de Python

| Framework   | Estilo                                              | Cuándo                                             |
| ----------- | --------------------------------------------------- | -------------------------------------------------- |
| **Django**  | "Baterías incluidas": ORM, admin, auth, migraciones | Aplicaciones completas con panel de administración |
| **Flask**   | Micro-framework síncrono (WSGI)                     | Servicios simples, mucho código existente          |
| **FastAPI** | API moderna sobre ASGI, async, tipado               | APIs JSON, microservicios, servicios de IA         |

FastAPI se apoya en **Starlette** (la capa web ASGI) y **Pydantic** (validación de datos). Su idea central: los
**type hints** de los parámetros definen la validación, la conversión y la documentación.

## Primer servicio

```python
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel, Field

app = FastAPI(title="Catálogo")

class ProductIn(BaseModel):
    name: str = Field(min_length=1, max_length=120)
    price_cents: int = Field(gt=0)
    currency: str = Field(pattern=r"^[A-Z]{3}$")

class ProductOut(BaseModel):
    id: str
    name: str
    price_cents: int
    currency: str

@app.post("/products", response_model=ProductOut, status_code=status.HTTP_201_CREATED)
def create_product(product: ProductIn) -> ProductOut:
    return catalog.create(product)

@app.get("/products/{product_id}", response_model=ProductOut)
def get_product(product_id: str) -> ProductOut:
    product = catalog.get(product_id)
    if product is None:
        raise HTTPException(status_code=404, detail="Producto no encontrado")
    return product
```

```bash
uvicorn app.main:app --reload   # desarrollo
# Documentación interactiva generada automáticamente en /docs (Swagger UI) y /redoc
```

- Si el body no cumple el modelo, FastAPI responde **422** con el detalle de cada error, sin ejecutar la función.
- `response_model` filtra la salida: aunque el objeto interno tenga más campos (un costo, un hash), sólo viaja lo
  declarado.
- Los parámetros de ruta (`product_id`) y de query (`limit: int = 20`) también se validan por su tipo.

## Inyección de dependencias

`Depends` declara qué necesita un endpoint; FastAPI lo resuelve en cada request:

```python
from typing import Annotated
from fastapi import Depends, Header

def get_session():
    session = SessionLocal()
    try:
        yield session               # se entrega al endpoint
    finally:
        session.close()             # se ejecuta al terminar la request

def current_user(authorization: Annotated[str, Header()], session=Depends(get_session)) -> User:
    user = auth.verify(authorization, session)
    if user is None:
        raise HTTPException(status_code=401, detail="No autenticado")
    return user

SessionDep = Annotated[Session, Depends(get_session)]
UserDep = Annotated[User, Depends(current_user)]

@app.get("/orders")
def list_orders(session: SessionDep, user: UserDep, limit: int = 20):
    return orders_repository.list_for(session, user.id, limit)
```

Las dependencias se encadenan (`current_user` usa la sesión) y en los tests se reemplazan con
`app.dependency_overrides`, sin tocar el código de los endpoints.

## def o async def

| Endpoint    | Dónde corre           | Usalo cuando                                                             |
| ----------- | --------------------- | ------------------------------------------------------------------------ |
| `async def` | En el event loop      | Todo lo que hace es async (httpx.AsyncClient, asyncpg, SQLAlchemy async) |
| `def`       | En un pool de threads | Usa librerías bloqueantes (un ORM síncrono, un SDK sin soporte async)    |

Mezclar mal es el error más común: un `async def` que llama a una librería bloqueante frena a **todas** las requests.

## Errores de dominio

```python
from fastapi import Request
from fastapi.responses import JSONResponse

class OutOfStockError(Exception):
    def __init__(self, sku: str):
        self.sku = sku

@app.exception_handler(OutOfStockError)
async def out_of_stock_handler(request: Request, error: OutOfStockError):
    return JSONResponse(status_code=409, content={"error": "out_of_stock", "sku": error.sku})
```

El dominio lanza sus propias excepciones y la capa web las traduce a HTTP en un solo lugar.

## Acceso a datos

Las opciones más usadas son **SQLAlchemy 2.0** (ORM y query builder, síncrono o async) con **Alembic** para
migraciones, o **SQLModel**, que combina SQLAlchemy y Pydantic. Las mismas reglas que en cualquier stack: consultas
parametrizadas, transacciones cortas, cuidado con el N+1 y migraciones versionadas.

## Testing con pytest

```python
# tests/conftest.py
import pytest
from fastapi.testclient import TestClient
from app.main import app, get_session

@pytest.fixture
def client(test_session):                     # test_session: otra fixture con una base de prueba
    app.dependency_overrides[get_session] = lambda: test_session
    yield TestClient(app)
    app.dependency_overrides.clear()

# tests/test_products.py
def test_rejects_negative_price(client):
    response = client.post("/products", json={"name": "Remera", "price_cents": -1, "currency": "ARS"})
    assert response.status_code == 422

@pytest.mark.parametrize("currency", ["ARS", "USD", "EUR"])
def test_creates_product(client, currency):
    response = client.post("/products", json={"name": "Remera", "price_cents": 1500, "currency": currency})
    assert response.status_code == 201
    assert response.json()["currency"] == currency
```

- Las **fixtures** se inyectan por nombre; con `yield` hacen limpieza; `conftest.py` las comparte.
- `parametrize` ejecuta el mismo test con distintos datos.
- Para integración, una base PostgreSQL real en un contenedor (testcontainers para Python o Docker Compose).

## Despliegue

FastAPI es una aplicación **ASGI**: se ejecuta con un servidor como **Uvicorn** (varios workers con
`uvicorn --workers N` o un process manager), en un contenedor detrás de un balanceador. La configuración llega por
variables de entorno (`pydantic-settings` las valida al arrancar) y el trabajo pesado o lento se delega a workers con
una cola.

## Resumen

FastAPI convierte los type hints en validación, documentación e inyección de dependencias. Con Pydantic en los bordes,
excepciones de dominio traducidas a HTTP, el uso correcto de def y async def, y tests con pytest y fixtures, tenés un
backend Python listo para un entorno profesional.
