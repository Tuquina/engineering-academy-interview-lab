## Qué es .NET

**.NET** es la plataforma de desarrollo de Microsoft, open source y multiplataforma (Windows, Linux y macOS). **C#**
es su lenguaje principal: orientado a objetos, estáticamente tipado, con mucha influencia de Java y, con los años,
características funcionales (LINQ, lambdas, records, pattern matching).

| Pieza        | Qué es                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------- |
| C#           | El lenguaje.                                                                                        |
| IL           | Lenguaje intermedio: el compilador de C# (Roslyn) genera IL dentro de un **assembly** (`.dll`).     |
| CLR          | El runtime: carga assemblies, compila el IL a código nativo con el **JIT** y administra la memoria. |
| BCL          | La librería base: colecciones, I/O, HTTP, JSON, criptografía.                                       |
| SDK          | Compilador, CLI (`dotnet`) y plantillas.                                                            |
| ASP.NET Core | El framework web.                                                                                   |

**Versiones**: sale una versión mayor por año, en noviembre. Las **pares son LTS** (3 años de soporte) y las
**impares STS** (2 años). .NET 10 (noviembre de 2025) es la LTS vigente; en producción suele elegirse una LTS. El
"**.NET Framework**" (hasta la 4.8) es la plataforma anterior, sólo para Windows: hoy se mantiene, pero los proyectos
nuevos usan .NET moderno.

## Tipos y variables

| Categoría | Tipos                          | Notas                                             |
| --------- | ------------------------------ | ------------------------------------------------- |
| Enteros   | `int`, `long`, `short`, `byte` | `int` es 32 bits, `long` 64                       |
| Decimales | `double`, `float`, `decimal`   | **`decimal` para dinero**: base 10, 28-29 dígitos |
| Otros     | `bool`, `char`, `string`       | `string` es un tipo de referencia inmutable       |

```csharp
int nights = 3;
var nightlyRate = 1250.50m;        // m: literal decimal
const int MaxRetries = 3;
string? promoCode = null;          // ? : puede ser null (con nullable habilitado)
```

**Nullable reference types** (C# 8, habilitado por defecto en los proyectos nuevos): el compilador distingue `string`
(nunca null) de `string?` (puede ser null) y advierte si desreferenciás algo que podría ser null. Es un análisis
estático; no cambia el runtime.

```csharp
int length = promoCode?.Length ?? 0;  // ?. y ?? como en TypeScript
promoCode ??= "SINPROMO";             // asigna si es null
```

## Control de flujo y pattern matching

```csharp
if (roomsLeft == 0) status = "sin disponibilidad";
else if (roomsLeft < 5) status = "últimas habitaciones";
else status = "disponible";

for (var i = 0; i < 3; i++) { }
foreach (var guest in guests) { }
while (retries < 3) retries++;

// switch expression (C# 8+): devuelve un valor y debe cubrir todos los casos
var label = status switch
{
    BookingStatus.Confirmed => "Confirmada",
    BookingStatus.CheckedIn or BookingStatus.CheckedOut => "En curso o finalizada",
    _ => "Pendiente",
};

// Pattern matching con tipos y propiedades
if (payment is CardPayment { Installments: > 1 } card)
{
    Console.WriteLine($"Pago en {card.Installments} cuotas");
}
```

## Métodos, clases y propiedades

```csharp
public class Booking
{
    private readonly List<BookingExtra> _extras = new();

    public Booking(string id, string guestId)           // constructor
    {
        Id = id;
        GuestId = guestId;
    }

    public string Id { get; }                           // propiedad de sólo lectura
    public string GuestId { get; }
    public BookingStatus Status { get; private set; } = BookingStatus.Pending;
    public decimal ExtrasTotal => _extras.Sum(e => e.Price * e.Quantity);   // propiedad calculada

    public void AddExtra(string code, decimal price, int quantity = 1)  // parámetro opcional
    {
        if (quantity <= 0) throw new ArgumentOutOfRangeException(nameof(quantity));
        _extras.Add(new BookingExtra(code, price, quantity));
    }
}

var booking = new Booking("b-1", "g-7");
booking.AddExtra("DESAYUNO", 1500m, quantity: 2);       // argumento con nombre
```

- Las **propiedades** (`{ get; set; }`) reemplazan a los getters y setters de Java, y se usan como campos.
- Modificadores de acceso: `public`, `private`, `protected`, `internal` (visible en el mismo assembly).
- La convención es **PascalCase** para tipos, métodos y propiedades, y `_camelCase` para campos privados.
- `namespace` organiza los tipos, como los paquetes de Java.

## Strings y colecciones básicas

```csharp
var message = $"Extras: {booking.ExtrasTotal:C}";  // interpolación con formato de moneda
var raw = """
    Texto multilínea (C# 11+)
    sin escapar "comillas".
    """;

string.Equals(a, b);                              // en C#, == en string compara contenido

var roomNumbers = new List<string> { "101", "102" };
roomNumbers.Add("201");

var freeRooms = new Dictionary<string, int> { ["doble"] = 5 };
if (freeRooms.TryGetValue("triple", out var count)) { /* existe */ }

int[] numbers = [1, 2, 3];                        // collection expressions (C# 12)
```

<Callout type="tip" title="Si venís de Java">
  C# te va a resultar familiar: clases, interfaces, genéricos y excepciones funcionan de forma parecida. Las
  diferencias que más se notan: propiedades en lugar de getters, `==` en `string` compara contenido, genéricos
  **reificados** (existen en runtime), structs definidos por el usuario, `async/await` nativo y LINQ.
</Callout>

## Resumen

C# compila a IL que ejecuta el CLR. Con el dotnet CLI, una versión LTS, tipos con nullable habilitado, switch
expressions, propiedades y las colecciones básicas ya podés programar. En la próxima lección vemos el modelo de tipos
en profundidad, LINQ y async/await.
