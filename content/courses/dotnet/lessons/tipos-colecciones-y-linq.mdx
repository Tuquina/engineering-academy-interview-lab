## Tipos de valor y de referencia

|            | Tipo de valor                                           | Tipo de referencia                                        |
| ---------- | ------------------------------------------------------- | --------------------------------------------------------- |
| Ejemplos   | `int`, `decimal`, `bool`, `DateTime`, `struct`, `enum`  | `class`, `string`, arrays, `delegate`, `record`           |
| Asignar    | Copia el valor completo                                 | Copia la referencia (ambas variables ven el mismo objeto) |
| Null       | No (salvo `int?`, que es `Nullable<int>`)               | Sí (marcado con `?` con nullable habilitado)              |
| Dónde vive | Inline: en el stack o dentro del objeto que lo contiene | En el heap administrado                                   |

```csharp
var a = new Point(1, 2);   // struct
var b = a;                 // copia
b.X = 10;                  // a.X sigue siendo 1 (si Point es mutable)

var c1 = new Cart();       // class
var c2 = c1;               // misma instancia
c2.Add("SKU-1");           // c1 también ve el ítem
```

Asignar un tipo de valor a `object` o a una interfaz lo **encapsula** en un objeto del heap (_boxing_), con su costo;
por eso los genéricos (`List<int>`) son preferibles a colecciones de `object`.

## Clases, structs, records e interfaces

```csharp
public interface IPaymentGateway
{
    Task<string> ChargeAsync(decimal amount, string token, CancellationToken ct);
}

public abstract class Payment                       // no se instancia
{
    public decimal Amount { get; init; }            // init: sólo se asigna al crear el objeto
    public abstract string Describe();
}

public sealed class CardPayment : Payment           // sealed: no se puede heredar
{
    public int Installments { get; init; } = 1;
    public override string Describe() => $"Tarjeta en {Installments} cuotas";
}

public record Money(decimal Amount, string Currency) // record posicional
{
    public Money Add(Money other) =>
        Currency == other.Currency ? this with { Amount = Amount + other.Amount }
                                   : throw new InvalidOperationException("Monedas distintas");
}

public readonly record struct DateRange(DateOnly From, DateOnly To);  // record de tipo de valor
```

| Elegí                      | Cuando                                                                   |
| -------------------------- | ------------------------------------------------------------------------ |
| `class`                    | Entidades con identidad y estado que cambia, servicios                   |
| `record`                   | Datos inmutables con igualdad por valor: DTOs, eventos, objetos de valor |
| `struct` / `record struct` | Valores chicos e inmutables que se crean en grandes cantidades           |

Herencia simple de clases y múltiples interfaces, como en Java. `virtual`/`override` controlan qué se puede
sobrescribir (por defecto, nada). Las interfaces pueden tener implementaciones por defecto desde C# 8.

## Genéricos y colecciones

```csharp
public sealed class Page<T>
{
    public required IReadOnlyList<T> Items { get; init; }   // required (C# 11): obligatorio al crear
    public string? NextCursor { get; init; }
}

public static T MaxBy<T, TKey>(IEnumerable<T> items, Func<T, TKey> key)
    where TKey : IComparable<TKey>                           // restricción
{ /* ... */ }
```

A diferencia de Java, los genéricos de .NET son **reificados**: `List<int>` y `List<string>` son tipos distintos en
runtime y `List<int>` guarda enteros sin boxing.

| Colección                            | Uso                | Complejidad típica           |
| ------------------------------------ | ------------------ | ---------------------------- |
| `List<T>`                            | Lista dinámica     | Índice O(1), `Contains` O(n) |
| `Dictionary<TKey, TValue>`           | Clave → valor      | O(1) promedio                |
| `HashSet<T>`                         | Sin duplicados     | `Contains` O(1) promedio     |
| `Queue<T>` / `Stack<T>`              | FIFO / LIFO        | O(1)                         |
| `PriorityQueue<TElement, TPriority>` | Heap               | O(log n)                     |
| `SortedDictionary`                   | Clave ordenada     | O(log n)                     |
| `ConcurrentDictionary`               | Acceso concurrente | O(1) promedio                |

Exponé colecciones como `IReadOnlyList<T>` o `IEnumerable<T>` para que quien las recibe no las modifique.

## LINQ

**LINQ** (Language Integrated Query) agrega operadores de consulta a cualquier colección:

```csharp
var paidByCustomer = orders
    .Where(o => o.Status == OrderStatus.Paid)
    .GroupBy(o => o.CustomerId)
    .Select(g => new { CustomerId = g.Key, Total = g.Sum(o => o.Total), Count = g.Count() })
    .OrderByDescending(x => x.Total)
    .Take(10)
    .ToList();

bool anyPending = orders.Any(o => o.Status == OrderStatus.Created);
var first = orders.FirstOrDefault(o => o.Id == id);      // null si no hay
var skus = orders.SelectMany(o => o.Items).Select(i => i.Sku).Distinct();
```

### Ejecución diferida

Una consulta LINQ sobre `IEnumerable<T>` **no se ejecuta cuando se define**, sino cuando se recorre (`foreach`,
`ToList`, `Count`, `First`…). Si la recorrés dos veces, se ejecuta dos veces.

Con **`IQueryable<T>`** (Entity Framework), los mismos operadores no se ejecutan en memoria: arman un árbol de
expresión que el proveedor traduce a SQL. Llamar a `ToList()` demasiado temprano trae toda la tabla a memoria y filtra
después: un error clásico de performance.

## Resumen

Entender tipos de valor y de referencia explica la mitad de las preguntas de C# en entrevistas. Records para datos,
clases para entidades, genéricos reificados, colecciones según su complejidad y LINQ con su ejecución diferida son la
base del código C# idiomático.
